# Voice clips

Put your three recorded clips here, with these exact names (all small letters).
`.mp3` is best; `.wav` also works (the app tries `.mp3` first, then `.wav`):

| File | When it plays | Idea for what to say |
|---|---|---|
| `scam.mp3` | Verdict is "Likely scam" | "Stop! This message looks like a scam. Don't click, don't pay, don't share your PIN." |
| `suspicious.mp3` | Verdict is "Suspicious" | "Careful o. This message has some warning signs. Check before you do anything." |
| `safe.mp3` | Verdict is "Probably safe" | "This one looks okay, but still stay careful." |

Tips:
- Keep each clip short (3–6 seconds) and small (under 200 KB) so it loads fast on slow data.
- Record on your phone, then convert to MP3 if needed (free tools: Audacity, or an online converter).
- If a file is missing, ScamEye just stays quiet. Nothing breaks.
